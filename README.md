# 服装模特展示工作流（四步 + 局部工艺特写）

用一套规范，把「模特穿着这件商品」的出图做稳定：输入商品图、模特图、姿势图和场景图，先出中性白模，再生成动作、穿衣服、匹配场景，最后补一张袖口／裤口的局部工艺特写。

## 为什么这么做

我最近在帮一些电商行业的用户做模特图。现在很多服饰类的用户，真正想要的是「模特穿这件衣服」的效果，而不是一张平铺图。但传统的模特穿衣或着装生成，有三个问题：

1. **动作遵循不准**：给一张姿势图，生成的动作跟它对不上。
2. **细节丢失**：想让它穿某件衣服，衣服本身的细节会大量丢失。
3. **参考性降低**：把模特图传进去，最后出来的东西跟真人的参考性也没那么强。

工作流的价值在于能按一个规范去执行，而不是每次靠运气。做的过程中发现：**AI 对「白模」的遵循性明显更好**。

## 四步

1. **提取白模**：把姿势图里的服装、面部、场景、水印全部去掉，只保留姿势、手部接触和景别。
2. **生成动作图**：每个模特的动作不一样，所以用白模生成对应的动作参考。
3. **穿衣**：把商品主图穿到白模确定的动作上，商品的颜色、版型、领口袖口裤口和可见工艺以商品图为准，不补造没看见的结构。
4. **匹配场景**：场景单独拆成一套四步制作流程，家具、墙面地面关系、光线、站位分开处理，稳定性和出图效果比一步到位好很多。

前三个中间步可以并行，且都可以人工复核——白模错了、场景歪了、身份跑偏了，能在成品之前拦下来。

## 一个必须处理的坑：裸露限制

生成白模时，平台对无衣人台有裸露审核限制，半身或近景姿势容易被安全系统直接拦掉。

处理方式是：在白模的关键部位补一层简单遮挡，让审核通过；同时这层遮挡**只能作用于生成阶段**，不能带进最终的穿衣成图，所以还要对传入内容再做一层屏蔽，把遮挡完全隔离在中间步骤里。

## 说明

- 样例来自真实电商客户素材，已做打码与示意处理，仅用于说明流程，不代表客户商品事实。
- 工作流已做成 LoomLoom 上的 SkillApp（固定费 0，仅模型透传用量），可批量跑。
- 白模是近似的姿势参考，不是精确骨骼或 3D 重建；手脚、左右、接触关系仍需人工复核。
